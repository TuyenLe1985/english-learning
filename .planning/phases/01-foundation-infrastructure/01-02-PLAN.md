    REDIS-BULLMQ SERVICE: image redis:7-alpine, container_name el_redis_bullmq. command: redis-server --appendonly yes --maxmemory-policy noeviction. CRITICAL: noeviction policy is MANDATORY — BullMQ stores delayed SRS review jobs as Redis sorted set entries. With any LRU policy, jobs evict under memory pressure; user review sessions vanish silently. AOF persistence ensures jobs survive container restarts. ports: "127.0.0.1:6379:6379". volumes: redis_bullmq_data:/data. healthcheck: test ["CMD", "redis-cli", "ping"], interval 10s, timeout 5s, retries 3.

    REDIS-CACHE SERVICE: image redis:7-alpine, container_name el_redis_cache. command: redis-server --maxmemory 256mb --maxmemory-policy allkeys-lru. No AOF — HTTP cache loss is a cache miss, not data loss. No volume needed. ports: "127.0.0.1:6380:6379" (external port 6380, internal 6379). healthcheck: test ["CMD", "redis-cli", "ping"], interval 10s, timeout 5s, retries 3.

    MINIO SERVICE: image minio/minio, container_name el_minio. command: server /data --console-address ":9001". env_file: .env. environment: MINIO_ROOT_USER using ${MINIO_ACCESS_KEY:-minioadmin}, MINIO_ROOT_PASSWORD using ${MINIO_SECRET_KEY:-minioadmin}. ports: "127.0.0.1:9000:9000" and "127.0.0.1:9001:9001". volumes: minio_data:/data. healthcheck: use curl-based check since mc may not have alias configured: test ["CMD", "curl", "-f", "http://localhost:9000/minio/health/live"], interval 10s, timeout 5s, retries 3, start_period 30s. (Research note A3: mc ready local requires prior alias setup — curl healthcheck is the safe fallback.)

    VOLUMES block at bottom: postgres_data, redis_bullmq_data, minio_data (redis-cache has no named volume).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Docker service → host | Port bindings must be localhost-only in dev to prevent external access |
| .env → Docker services | env_file injects secrets into containers; .env must be gitignored |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-03 | Tampering | Docker port bindings | mitigate | All dev ports bind to "127.0.0.1:" prefix — prevents unintended exposure on public network interfaces |
| T-1-04 | Information Disclosure | Docker env_file | mitigate | .env is gitignored (Plan 01 Task 1); docker-compose.yml reads from .env via env_file directive; no secrets hardcoded in compose file |
| T-1-05 | Denial of Service | redis-bullmq eviction | mitigate | noeviction policy — Redis rejects writes when memory full rather than evicting BullMQ jobs; AOF persistence survives restart |
| T-1-06 | Elevation of Privilege | MinIO root credentials | accept | Dev uses minioadmin/minioadmin placeholders; production credentials must be changed per .env.example CHANGE_ME guidance |
  T-1-SC | Tampering | npm/Docker image installs | mitigate | Docker images are official (postgres:16-alpine, redis:7-alpine, minio/minio) from Docker Hub official repositories |
</threat_model>
