<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CI environment → secrets | CI yaml contains test-only credentials (postgres/postgres) — not real production secrets |
| GitHub Actions → npm registry | CI installs packages with --frozen-lockfile; prevents accidental upgrades |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-16 | Information Disclosure | CI YAML credentials | accept | CI YAML contains postgres/postgres for test DB only — not production credentials; safe to commit; production secrets use GitHub Secrets |
| T-1-17 | Tampering | pnpm lockfile drift | mitigate | CI uses --frozen-lockfile — if lockfile is out of sync with package.json, install fails rather than silently upgrading packages |
| T-1-18 | Tampering | prisma migrate dev in CI | mitigate | CI uses db:migrate:deploy (not migrate dev) — deploy applies committed migrations only; dev would attempt to create new migrations and fail asking for name |
| T-1-SC | Tampering | CI action installs | mitigate | All GitHub Actions are pinned (actions/checkout@v4, pnpm/action-setup@v3, actions/setup-node@v4) — pinned to major version, not floating tags |
</threat_model>
