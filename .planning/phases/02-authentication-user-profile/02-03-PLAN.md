## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser form → server action | untrusted email/password input |
| server action → Redis | rate-limit counters |
| server action → Resend API | email send |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Information Disclosure | password storage | mitigate | bcrypt 12 rounds; passwordHash never equals plaintext; never logged (RESEARCH Don't Hand-Roll) |
| T-02-05 | Elevation of Privilege | verification token reuse/expiry | mitigate | 24h expiry; token deleted on use; unknown tokens rejected (Security Domain) |
| T-02-06 | Denial of Service | resend email abuse | mitigate | Redis rate-limit 1/60s + 3/hour, survives restart (D-02, Pitfall 5) |
| T-02-07 | Spoofing | unverified account accessing content | mitigate | signIn callback gates on emailVerified (D-01) |
</threat_model>
