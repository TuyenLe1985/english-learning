## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → NestJS /api/users, /api/profile | Bearer JWE; guard enforces identity |
| browser → MinIO/R2 presigned PUT | direct upload bypasses NestJS |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-14 | Elevation of Privilege | /api/users/me, /api/profile/* | mitigate | @UseGuards(JwtAuthGuard) on every endpoint; userId read from validated token, never from request body |
| T-02-15 | Tampering | malicious avatar upload | mitigate | ContentType allow-list + sizeBytes <= 2MB checked before presigned URL issued (D-08) |
| T-02-16 | Tampering | avatarUrl stored as full CDN URL | mitigate | Store only the storage key (RESEARCH Anti-Pattern); URL reconstructed at read time |
| T-02-SC3 | Tampering | @aws-sdk/* + boring-avatars installs | mitigate | Both [ASSUMED] in audit (official AWS SDK / OSS); covered by Plan 01 legitimacy checkpoint pattern |
</threat_model>
