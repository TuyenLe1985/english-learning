  <behavior>
    - getCategories() → returns 8 categories, each { slug, name, wordCount } where wordCount = count of VocabularyWord rows in that category (VOCAB-01)
    - getWordsByCategory(category, page, limit=20) → { words, total, page, limit, totalPages }, ordered word ASC, skip=(page-1)*limit (VOCAB-01, D-12)
    - getWordDetail(wordId) → VocabularyWordDto with definition, partOfSpeech, examples[], synonyms[], pronunciationKey, audioStorageKey, cefrLevel; throws NotFoundException on missing id (P2025) (VOCAB-02)
    - getMyWords(userId, status?, page) → user's UserVocabularyItems joined with SrsCard, mapped to status (new/learning/reviewing/mastered) with nextReviewDate from SrsCard.due; filtered when status provided (VOCAB-07)
    - assignExerciseTypes(words[]) → assigns one of the 6 types (flashcard, matching, cloze, context, synonym, recall) per word; at most 2 matching exercises per 10-word session; matching consumes 4 words (VOCAB-03, D-05, D-08)
    - Every endpoint rejects requests without a valid JWT (JwtAuthGuard)
    - userId always sourced from req.user.userId, never request body
  </behavior>
