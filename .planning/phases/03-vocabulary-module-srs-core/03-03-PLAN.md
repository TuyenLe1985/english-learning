| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Information Disclosure | submitReview, getDueQueue | mitigate | Every SrsCard query scoped by userId from JWT (findFirst { id, userId }); a user can never read or mutate another user's cards |

| T-03-08 | Denial of Service | POST /api/srs/enroll | mitigate | enrollWord is idempotent (upsert) so repeated taps cannot mass-create cards; @nestjs/throttler available in stack if abuse observed |
| T-03-09 | Elevation of Privilege | all SRS endpoints | mitigate | @UseGuards(JwtAuthGuard) on every method; SrsModule imports AuthModule |
