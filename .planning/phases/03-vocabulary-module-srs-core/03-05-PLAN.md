Vertical slice: the mixed-type practice session, end to end. After this plan a logged-in user can press "Practice this set" on a category, complete a 10-word session that draws from all 6 exercise types, see a results screen, and add the words they want into their SRS review schedule.

All session state is held in React state; one batch POST at the end (RESEARCH anti-pattern: no mid-session API calls).
Output: practice page, session orchestrator, 6 exercise components, results screen, session-complete relay, and a flashcard component test.
</objective>
