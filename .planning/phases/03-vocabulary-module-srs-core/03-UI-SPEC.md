## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gap inside buttons, inline badge padding |
| sm | 8px | Card internal gap, list item vertical rhythm |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding within page |
| xl | 32px | Page section breaks (between category grid and header) |
| 2xl | 48px | Major layout breaks |
| 3xl | 64px | Page top padding on content pages |

Exceptions:
- Touch targets on rating buttons (Again / Hard / Good / Easy): minimum 44px height to meet WCAG 2.5.5 target size.
- Flashcard exercise card: minimum 280px height to give sufficient space for definition text.
- Matching exercise tap targets: minimum 44px height per row item.

Source: 8-point scale default; exceptions derived from VOCAB-06 and D-08 interaction requirements.

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px | 400 (regular) | 1.5 | Definition text, example sentences, word list items |
| Label | 14px | 400 (regular) | 1.4 | Word list metadata, badge text, pagination label, toast messages |
| Heading | 20px | 600 (semibold) | 1.2 | Word title on detail page, category card name, section headings |
| Display | 28px | 600 (semibold) | 1.2 | Flashcard front (target word), review card word |

Font: Inter (var(--font-inter)), system-ui fallback.

Rules:
- Use exactly 2 weights: 400 (regular) and 600 (semibold). Do not introduce 500 or 700.
- Phonetic key text (`/prəˈnʌnsieɪʃən/`) uses Body (16px/400) rendered in `text-muted-foreground` — visually subordinate to the headword.
- SRS status label ("Reviewing", "Mastered") uses Label (14px/400).
- Session score "8/10 correct" uses Heading (20px/600).

Source: Defaults based on established shadcn/zinc New York base; display size derived from flashcard legibility requirement (D-03, VOCAB-06).

**Semantic accent overrides for this phase** (explicit list):
- `primary` (`hsl(240 5.9% 10%)` / near-black): "Practice this set" CTA button, "Mark as learned" button, "Start Session" button, "Add to Review" dialog confirm button, rating button active state.
- CEFR badge colors (pre-established in Phase 2, carry forward without modification):
  - B1: `bg-blue-100 text-blue-700` (informational, not primary CTA)
  - B2: `bg-emerald-100 text-emerald-800`
  - C1: `bg-violet-100 text-violet-800`
- SRS status badge colors (new for Phase 3):
  - New: `bg-zinc-100 text-zinc-600` (neutral — not yet started)
  - Learning: `bg-amber-100 text-amber-700` (in-progress signal)
  - Review: `bg-blue-100 text-blue-700` (active study signal)
  - Mastered: `bg-green-100 text-green-700` (completion signal)
- Rating buttons:
  - Again: `text-red-600` label on neutral button surface
  - Hard: `text-orange-500` label on neutral button surface
  - Good: `text-green-600` label on neutral button surface
  - Easy: `text-blue-600` label on neutral button surface
- Correct/incorrect exercise feedback: `bg-green-50 border-green-500` (correct), `bg-red-50 border-red-500` (incorrect)

Accent is NOT used for: hover states, card borders, input focus rings, plain text links, category card icons (use lucide default `currentColor`).

Source: CSS variables pre-populated from globals.css; SRS status colors and rating button colors are Phase 3 additions, using Tailwind semantic palette to match existing CEFR badge pattern.

## Interaction States

### Flashcard Exercise (VOCAB-03)

| State | Visual |
|-------|--------|
| Front (default) | White card, Display text (word, 28px/600), phonetic below in muted, play button |
| Flipping | Framer Motion `rotateY(0 → 180deg)`, duration 0.4s, `easeInOut`, `transformStyle: preserve-3d` |
| Back (revealed) | Card shows definition (Body 16px/400), example sentence in muted |
| Touch target | Full card is tappable — not just a flip button |

### Matching Exercise (VOCAB-03, D-08)

| State | Visual |
|-------|--------|
| Default | Left column: 4 word chips. Right column: 4 definition chips. All `bg-secondary`. |
| Word selected | Word chip: `bg-primary text-primary-foreground` (highlighted) |
| Definition selected (match attempt) | Evaluates immediately on second tap |
| Correct match | Both chips animate out: `opacity 0, scale 0.9`, duration 0.3s. Paired. |
| Incorrect match | Both chips: Framer Motion `x: [-6, 6, -6, 0]` shake, 0.3s. Then deselect. |
| All 4 matched | Exercise complete — advance to next word |

### Rating Buttons (VOCAB-06)

Buttons appear only AFTER flashcard is flipped (answer revealed). Layout: 4 equal-width buttons in a row.

| Rating | Label | Color cue | Min height |
|--------|-------|-----------|------------|
| Again | "Again" | `text-red-600` | 44px |
| Hard | "Hard" | `text-orange-500` | 44px |
| Good | "Good" | `text-green-600` | 44px |
| Easy | "Easy" | `text-blue-600` | 44px |

All four use `variant="outline"` (shadcn Button). Color is applied to text only, not button background.

### SRS Status Badge (VOCAB-07)

| Status | Badge copy | Colors |
|--------|-----------|--------|
| New | "New" | `bg-zinc-100 text-zinc-600` |
| Learning | "Learning" | `bg-amber-100 text-amber-700` |
| Review | "Review" | `bg-blue-100 text-blue-700` |
| Mastered | "Mastered" | `bg-green-100 text-green-700` |

### Pronunciation Play Button (D-10)

- Icon: `Volume2` (lucide). Size: 16px. Color: `text-muted-foreground`.
- On click: button disabled (`pointer-events-none`) while audio plays, restored after.
- No loading spinner needed — audio starts within ~100ms (R2 CDN or instant `speechSynthesis`).
- Placement: inline-flex immediately after phonetic text `/prəˈnʌnsieɪʃən/`.

## Page Layouts

### `/vocabulary` — Category Grid (D-09, VOCAB-01)

- Layout: 2-column grid on mobile (≥375px), 4-column grid on desktop (≥768px).
- 8 category cards using shadcn `Card` component.
- Each card: lucide icon (top), category name (Heading 20px/600), word count (Label 14px/400 muted).
- Category icons (Lucide):
  - Business: `Briefcase`
  - Travel: `Plane`
  - Technology: `Cpu`
  - Education: `GraduationCap`
  - Health: `Heart`
  - Daily Life: `Home`
  - Social Topics: `Users`
  - Academic English: `BookOpen`
- Page heading: "Vocabulary" (Display 28px/600).
- Sub-heading: "Browse by category" (Body 16px/400 muted).

### `/vocabulary/[category]` — Word List (D-12, VOCAB-01)

- Page heading: Category name (Display 28px/600) + word count (Label 14px/400 muted).
- "Practice this set" button (primary, top-right).
- Word list: each item = `WordListItem` component (word, part of speech, CEFR badge, SRS status if enrolled).
- Pagination: 20 words/page, alphabetical A–Z. Prev/Next using shadcn `Pagination` component at bottom.
- Loading state: 5 skeleton rows (shadcn `Skeleton`).
- No search/filter in Phase 3.

### `/vocabulary/[category]/[wordId]` — Word Detail (D-09, VOCAB-02, D-10, D-11)

- Page heading: Word (Display 28px/600) + phonetic text inline + play button.
- Part of speech badge (Label 14px/400, `bg-secondary`).
- CEFR badge (reuse `CefrBadge`).
- shadcn `Tabs`: "Definition" | "Examples" | "Synonyms" | "Usage".
  - Definition tab: definition text (Body 16px/400).
  - Examples tab: list of 2–3 example sentences (Body 16px/400, italicized).
  - Synonyms tab: comma-separated synonyms as `Badge` chips.
  - Usage tab: common usage patterns (Body 16px/400).
- "Mark as learned" button: `variant="default"` (primary), full-width on mobile. Shows "In your review schedule" (muted, disabled) if word is already enrolled.
- "Practice this set" link at bottom, `variant="ghost"`.

### `/vocabulary/[category]/practice` — Practice Session (D-05, D-06, D-07, VOCAB-03)

- Full-screen focus layout: no sidebar navigation visible during session.
- Progress bar (shadcn `Progress`): `value={(currentIndex / 10) * 100}`. Label: "3 of 10" (Label 14px/400 muted).
- Exercise card occupies center: min-height 280px, max-width 600px, centered.
- Exercise type label (Label 14px/400 muted): "Flashcard", "Matching", "Fill in the blank", etc.
- Bottom action area: exercise-specific buttons (Reveal / Check / Next).
- Session Results screen (D-07): score "8/10 correct" (Display 28px/600), time taken (Label 14px/400 muted), list of incorrect words (WordListItem compact), dialog for "Add to SRS" (shadcn `Dialog`).

### `/review` — SRS Review Queue (D-04, VOCAB-06)

- Page heading: "Review" (Display 28px/600) + due count subtitle: "5 cards due" (Body 16px/400 muted).
- Queue progress: shadcn `Progress`, `value={(reviewed / total) * 100}`. Label: "2 of 5 reviewed".
- Review card: centered, max-width 480px. Shows word (Display 28px/600) initially.
- "Show Answer" button: `variant="outline"`, full-width.
- After reveal: definition + example sentence shown. Rating buttons appear below.
- Session complete screen: "All caught up!" heading + "Come back tomorrow" body + "Back to Dashboard" CTA.

### `/vocabulary/my-words` — Personal Vocabulary List (VOCAB-07)

- Page heading: "My Vocabulary" (Display 28px/600).
- Filter bar: 5 tabs — "All" | "New" | "Learning" | "Review" | "Mastered" (shadcn `Tabs`, top of list).
- Word list: each item shows word, definition snippet (1 line), CEFR badge, SRS status badge, next review date (Label 14px/400 muted: "Due: Jun 15").
- Loading state: shadcn `Skeleton` rows.
- Pagination: 20 words/page, Prev/Next at bottom.

| Trigger | Message | Action |
|---------|---------|--------|
| Word detail fails to load | "Couldn't load this word" | "Try again" button (retry same request) |

### Destructive Actions

There are no destructive actions in Phase 3 (no delete, no remove from SRS). No confirmation dialogs required for destructive actions.

The "Add to review schedule?" dialog (D-07) is a confirmation for a constructive action, not destructive. Cancel is "Skip", not "Cancel".

## Animation Contract

All animations use Framer Motion (`framer-motion@12.40.0`). Do not use raw CSS transitions for these components.

| Component | Animation | Duration | Easing |
|-----------|-----------|----------|--------|
| Flashcard flip | `rotateY: 0 → 180` | 0.4s | `easeInOut` |
| Matching — correct pair dismiss | `opacity: 1→0, scale: 1→0.9` | 0.3s | `easeOut` |
| Matching — incorrect pair shake | `x: [0, -6, 6, -6, 0]` | 0.3s | `easeInOut` |
| Rating buttons appear | `opacity: 0→1, y: 8→0` | 0.2s | `easeOut` |
| Session complete | `opacity: 0→1, scale: 0.95→1` | 0.3s | `easeOut` |

`transformStyle: "preserve-3d"` and `backface-visibility: "hidden"` must be applied as inline styles on flashcard faces (Tailwind does not expose these by default in v3).

## Accessibility Requirements

- All exercise interactive elements must be keyboard-navigable (Tab + Enter/Space).
- Rating buttons must have `aria-label`: "Rate as Again", "Rate as Hard", "Rate as Good", "Rate as Easy".
- Flashcard flip: `aria-pressed={flipped}` on the card container.
- Matching exercise: word chips use `role="button"` with `aria-selected={isSelected}`.
- Progress bar: `aria-label="Session progress"` on the shadcn `Progress` component.
- Play pronunciation button: `aria-label="Play pronunciation of {word}"`.
- Status filter tabs: shadcn `Tabs` provides `role="tablist"` / `role="tab"` / `role="tabpanel"` automatically.
- SRS status badges: `aria-label="Status: Mastered"` (screen readers should not have to guess from color alone).
- Empty states: `role="status"` on the empty state container.

## React Query Cache Strategy

Declared here so executor uses consistent stale times:

| Query | `staleTime` | `gcTime` | Rationale |
|-------|------------|---------|-----------|
| `["vocab-categories"]` | 5 minutes | 10 minutes | Category data changes only on content pipeline runs |
| `["vocab-words", category, page]` | 2 minutes | 5 minutes | Word list is stable; short TTL for new enrollments to surface |
| `["vocab-word", wordId]` | 5 minutes | 10 minutes | Individual word data rarely changes |
| `["srs-queue"]` | 0 (always fresh) | 1 minute | SRS timing is critical; always refetch on mount |
| `["my-words", status, page]` | 30 seconds | 2 minutes | List changes after each review/enrollment |

Global `defaultOptions`: `{ queries: { staleTime: 30_000 } }` as baseline; overridden per-query above.
