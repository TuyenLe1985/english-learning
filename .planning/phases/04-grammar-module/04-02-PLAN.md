  <behavior>
    - getAreas(): returns all GrammarArea ordered by sortOrder, each mapped to GrammarAreaDto with topicCount = count of related topics.
    - getTopicsByArea(areaSlug): resolves area by slug, returns its topics ordered by sortOrder as GrammarTopicDto with lessonCount; masteryPct null unless caller passes userId.
    - getLessonsByTopic(topicSlug, userId): returns GrammarTopicDetailDto = { topic (with masteryPct from GrammarProgress for this user/topic, null if none), lessons[] each with questionCount }.
    - getLessonDetail(lessonSlug): findUniqueOrThrow on slug include questions; maps to GrammarLessonDetailDto; throws NotFoundException on Prisma P2025.
    - completeSession(userId, dto): grammarAttempt.createMany (questionId, userId, isCorrect, userAnswer ?? null, skipDuplicates false); resolve topicId from lessonId; read existing GrammarProgress; newAttempts = existing.attempts + dto.attempts.length, newCorrect = existing.correct + countCorrect, masteryPct = newCorrect/newAttempts; grammarProgress.upsert on userId_topicId; returns { score: correctCount, total: dto.attempts.length, masteryPct }.
    - getWeakQuestions(topicSlug, userId): resolve topicId from slug; fetch all questionIds in topic's lessons; fetch user's attempts for those questionIds ordered attemptedAt desc; dedupe to most-recent per questionId in JS; return GrammarQuestionDto[] for those whose latest isCorrect=false (empty array if none).
