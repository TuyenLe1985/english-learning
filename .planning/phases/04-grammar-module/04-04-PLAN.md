<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → Next.js relay route | session cookie validated by auth() before any proxy |
| Next.js relay → NestJS | Bearer token forwarded via fetchWithAuth |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-10 | Elevation of Privilege | grammar relay routes | mitigate | every relay route calls `await auth()` and returns 401 before proxying; NestJS JwtAuthGuard is the authoritative second gate |
| T-04-11 | Information Disclosure | mastery on topic page | mitigate | masteryPct comes from NestJS scoped to req.user.userId; relay never passes a client-supplied userId |
| T-04-12 | Spoofing | session token in Server Components | accept | getSessionToken() reads the httpOnly NextAuth cookie server-side; not exposed to client JS |
</threat_model>
