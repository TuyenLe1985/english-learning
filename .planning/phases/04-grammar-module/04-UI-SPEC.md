# Phase 4 — UI Design Contract

> Visual and interaction contract for the Grammar Module frontend. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn/ui |

| Component library | Radix UI (via shadcn) |

**Third-party dependency (new):** `@dnd-kit/core` + `@dnd-kit/sortable` — for DragAndDropExercise only. Not a shadcn registry entry; installed via pnpm directly. No registry vetting gate required.

## Spacing Scale

Declared values (multiples of 4 — matches Tailwind default scale):

| Token | Value | Tailwind Class | Usage |
|-------|-------|----------------|-------|
| xs | 4px | `gap-1`, `p-1` | Icon gaps, inline chip padding |
| sm | 8px | `gap-2`, `p-2` | Compact badge spacing, between label + value |
| md | 16px | `gap-4`, `p-4` | Default element spacing within cards |
| lg | 24px | `gap-6`, `p-6` | Exercise card internal padding (matches vocab pattern) |
| xl | 32px | `gap-8`, `mb-8` | Page heading bottom margin, section breaks |
| 2xl | 48px | `py-12` | Empty state vertical padding |
| 3xl | 64px | `py-16` | Full-page loading/error states |

Exceptions:
- Touch targets minimum 44px height (`min-h-[44px]`) on all interactive buttons — established pattern from Phase 3, matches WCAG 2.5.5
- Progress bar height 8px (`h-2`) — below standard scale but established by vocab practice session
- Area card icon: 32px (`h-8 w-8`) — established by CategoryCard
- Explanation rule card: `px-4 py-3` (12px vertical, 16px horizontal) for density in scrollable rule sections

## Typography

| Role | Size | Weight | Line Height | Tailwind | Used For |
|------|------|--------|-------------|----------|----------|
| Display | 28px | 600 (semibold) | 1.2 | `text-[28px] font-semibold leading-tight` | Score display on results screen; flashcard word |
| Heading | 30px (text-3xl) | 600 (semibold) | 1.2 | `text-3xl font-semibold` | Page titles (/grammar, /grammar/[area], /grammar/[area]/[topic], lesson page) |
| Body | 16px | 400 (regular) | 1.5 | `text-base leading-relaxed` | Lesson explanation text, exercise prompts, sentence transformation sentences |
| Label | 14px | 400 (regular) | 1.4 | `text-sm` | Subtitles, word counts, CEFR badge text, progress counter "n of total" |
| Micro | 12px | 400 (regular) | 1.4 | `text-xs` | Topic count on area cards, muted secondary metadata |

Font weights used: 400 (regular) and 600 (semibold) only — no 500, no 700. Matches established Phase 3 vocabulary pattern.

**Explanation block special rendering:**
- Grammar rule text: `text-base font-semibold text-foreground` inside a `bg-zinc-100 dark:bg-zinc-800` rule card
- Example sentences: `text-sm text-foreground italic` rendered as a list with `•` prefix, one per line

| DraggableWord (being dragged) | `ring-2 ring-primary opacity-80` |

| Re-placement behavior | Dropping on an occupied blank returns the current occupant to the word bank |
| "Check" button | `<Button className="min-h-[44px]" disabled={hasUnfilledBlanks}>Check</Button>` — disabled until all blanks filled |

**dnd-kit implementation notes:**
- Use `DndContext` with `PointerSensor` (handles both mouse and touch)
- `DragOverlay` for smooth drag preview
- `useDraggable` for DraggableWord chips
- `useDroppable` for DroppableBlank slots
- Sensor activation: pointer sensor with `activationConstraint: { distance: 5 }` to prevent accidental drag on mobile tap
