## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Worktree base-commit race | When spawning 3 parallel worktree agents in the same message, 2 of 3 got wrong base commit (old phase 4 HEAD instead of current HEAD after 05-01 sequential commit). Agents returned exit 0 with no commits. | advisory | Before spawning parallel worktree agents: (1) verify current HEAD with `git rev-parse HEAD`, (2) dispatch agents one at a time with `run_in_background: true` in separate messages (not all in one message), (3) check worktrees with `git worktree list --porcelain` and verify all HEAD hashes match expected base before proceeding. |
| TDD gate RED-in-wrong-plan | Phase 5 design puts ALL RED test scaffolds in plan 05-01 (a shared foundation wave). Plans 05-02/03/04 are GREEN-only. The MVP+TDD gate looks for `test(05-0X):` commits per plan — it found none and tripped. | advisory | In executor agent prompts for 05-02/03/04, include explicit `<tdd_gate_override>` block stating the RED tests are in plan 05-01 (`test(05-01):` commit) and the gate should be bypassed. This is by design. |
