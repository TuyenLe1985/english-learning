    - Reads words.csv (word_id, word, stem_word_id) and word_pos.csv (word_pos_id, word_id, level, ...)

    classifyPassage(text: string): { cefrLevel: 'B1'|'B2'|'C1', cefrConfidence: number } method:
    - Tokenize with natural.WordTokenizer
    - Tag POS with natural.BrillPOSTagger (rules path: find in node_modules/natural/lib/natural/brill_pos_tagger/data/English/ — verify exact directory post-install; use path.join(require.resolve('natural'), '../...'))
    - Filter out tokens tagged NNP or NNPS (proper nouns)
    - Vocabulary score (50%): count content words matching B2+ level / total content words; map to B1/B2/C1 band
    - Sentence length score (25%): split on [.!?]+; average words per sentence; >25 avg = C1 indicator, 15-25 = B2, <15 = B1
    - Syntactic complexity score (25%): count occurrences of subordinate clause markers (because, although, whereas, however, nevertheless, consequently, moreover, furthermore, despite, notwithstanding) per 100 words; >3 = C1, 1-3 = B2, <1 = B1
    - Normalize A1/A2 → B1, C2 → C1 in vocabulary lookup
    - Combine weighted scores to get final cefrLevel
    - Confidence = 1 - (std deviation of band score spread / max possible spread); passes PIPE-04 threshold check at 0.65
