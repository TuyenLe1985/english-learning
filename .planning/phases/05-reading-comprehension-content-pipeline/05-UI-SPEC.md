## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, tight badge spacing |
| sm | 8px | Compact element spacing, filter pill gaps |
| md | 16px | Card internal padding, form field spacing |
| lg | 24px | Section padding, card grid row gap |
| xl | 32px | Layout column gaps, major section breaks |
| 2xl | 48px | Page section separators |
| 3xl | 64px | Page-level top/bottom padding |

Exceptions:
- Touch targets (buttons, "Add to SRS" in popover, bookmark icon): minimum 44px height — `min-h-[44px]` (consistent with prior phases).
- Passage body text line-height maps to 1.75 (not a spacing token) — required for comfortable long-form reading.
- Sticky notes panel width: 320px desktop, full-width mobile bottom sheet.

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body (passage) | 18px | 400 (regular) | 1.75 | Passage prose text — larger than UI body for reading comfort |
| Body (UI) | 14px | 400 (regular) | 1.5 | Labels, metadata, muted descriptions |
| Label | 14px | 600 (semibold) | 1.4 | Question prompts, card titles, filter labels |
| Heading | 20px | 600 (semibold) | 1.2 | Passage title on passage page, section headers |
| Display | 28px | 600 (semibold) | 1.1 | Inline score card headline ("You scored X/Y") |

Notes:
- Passage body uses `text-[18px] leading-[1.75]` for the `PassageRenderer` component — this is a deliberate departure from UI body size to match reading app conventions (Medium, Substack).
- All other UI text uses `text-sm` (14px) matching prior phases.
- Max 2 font weights in use: 400 (regular) and 600 (semibold). No bold (700) or medium (500).
- Source: established in Phases 2–4 (`text-sm font-semibold`, `text-[28px] font-semibold`).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `hsl(0 0% 100%)` — `--background` | Page background, passage reading area |
| Secondary (30%) | `hsl(240 4.8% 95.9%)` — `--secondary` / `--muted` | Filter bar background, notes panel, sidebar |
| Accent (10%) | `hsl(240 5.9% 10%)` — `--primary` | Primary CTA buttons, active filter pill, "Add to SRS" button |
| Destructive | `hsl(0 84.2% 60.2%)` — `--destructive` | Remove highlight confirmation only |
| Highlight overlay | `bg-amber-100/70` — `rgba(253,230,138,0.7)` | Highlighted text spans in passage (READ-04) |
| CEFR B1 | `bg-blue-100 text-blue-700 border-blue-200` | B1 Intermediate badges |
| CEFR B2 | `bg-emerald-100 text-emerald-800 border-emerald-200` | B2 Upper Intermediate badges |
| CEFR C1 | `bg-violet-100 text-violet-800 border-violet-200` | C1 Advanced badges |

Accent (`--primary`) reserved for:
1. Primary CTA button: "Start Reading" on browse card, "Add to SRS" in word tap popover
2. Active/selected filter pill state on the browse page filter bar
3. Bookmark icon filled state (amber-400 fill for filled bookmark, not primary — see exception below)

Bookmark filled state exception: filled bookmark uses `text-amber-400` (warm, recognizable "saved" signal). Unfilled bookmark uses `text-muted-foreground`. This matches convention established in vocabulary word-list (star/bookmark icons).

Highlight overlay: `bg-amber-100/70` — yellow-amber at 70% opacity over white passage background creates readable text contrast while clearly indicating the highlight region. Applied as a `<mark>` element or span with `bg-amber-100/70` class.

Dark mode: All CSS variables already defined in `globals.css` for `.dark`. Phase 5 respects the existing dark mode tokens without additions.

## Screen Contracts

### Screen 1: Reading Browse Page (`/reading`)

Layout: Full-width page within the dashboard layout (`max-w-screen-xl px-4 py-8`).

Sub-sections:
1. **Page header** — `h1` "Reading Passages" at heading size (20px, semibold), subtitle "Browse passages at your CEFR level" at body UI size (14px, muted).
2. **Filter bar** — horizontal scrollable row of filter controls:
   - CEFR level: `Tabs` component with values "All", "B1", "B2", "C1". Active tab has primary fill.
   - Topic: `Select` dropdown. Placeholder "All topics". Options: Technology, Business, Travel, Education, Health, Daily Life, Social Topics, Academic.
   - Content type: `Select` dropdown. Placeholder "All types". Options: Article, News, Blog Post, Academic, Story, Opinion.
   - Filter bar background: `bg-muted rounded-lg p-3` to visually group filters.
3. **Passage grid** — responsive grid: 1 column (mobile), 2 columns (md), 3 columns (xl). Gap: `gap-6` (24px). Each cell is a passage card.
4. **Pagination** — centered below the grid. Uses existing `Pagination` shadcn component. 20 passages per page.
5. **Empty state** — centered message when filters return no results.

Passage card anatomy:
- Container: `Card` with `hover:shadow-md transition-shadow` and `cursor-pointer`.
- Top row: `CefrBadge` (level) on left, `Bookmark` icon toggle on right (Lucide `Bookmark` / `BookmarkCheck`).
- Title: `text-sm font-semibold text-foreground` — max 2 lines, `line-clamp-2`.
- Metadata row: topic `Badge` (secondary variant) + word count `"~450 words"` at `text-xs text-muted-foreground`.
- No description excerpt on the card — title + CEFR + topic is sufficient.
- Card height: auto (consistent within grid row via CSS grid implicit row height).
- "Start Reading" is NOT a visible CTA on the card — the entire card is a link (`<Link href="/reading/[passageId]">`).

### Screen 2: Passage Reader Page (`/reading/[passageId]`)

Layout: Two-column desktop layout (passage + sticky notes panel), single-column mobile.

Sub-regions:

**2a. Passage header** (above passage body):
- Back link: `← Back to Reading` at `text-sm text-muted-foreground` with `ChevronLeft` Lucide icon.
- Passage title: heading size (20px, semibold, `text-foreground`).
- Metadata row: `CefrBadge` + topic `Badge` (secondary) + word count + content type, all `text-xs text-muted-foreground`, separated by `·` character.
- Action row: Reading timer display (passive, `Clock` icon + elapsed time), Bookmark toggle button, Notes toggle button. All inline at `text-sm`.

**2b. Passage body** (the readable content area):
- Container: `max-w-[65ch] mx-auto` — optimized line length for reading comfort.
- Font: `text-[18px] leading-[1.75] text-foreground`.
- Rendered via `PassageRenderer` component: sanitizes HTML (DOMPurify), wraps each word in `<span data-word="{normalized-word}" class="cursor-pointer hover:bg-muted/50 rounded-sm px-0.5">`.
- Highlight overlay: highlighted spans receive `bg-amber-100/70 rounded-sm` class applied by the highlight restore logic.
- Paragraph spacing: `prose` style spacing — `mb-4` between paragraphs.
- No `max-w` constraint on the outer page wrapper; the passage body imposes its own `max-w-[65ch]` for readability.

**2c. Questions section** (below passage body, separated by `Separator`):
- Section header: "Comprehension Questions" at `text-sm font-semibold text-foreground`, with score accumulator `"3 / 6 correct"` updating inline.
- Each question is a `Card` with:
  - Question number: `text-xs text-muted-foreground` "Question 1 of 6"
  - Prompt: `text-sm font-semibold text-foreground`
  - Answer options: `Button` with `variant="outline"` for each option. On selection: correct option becomes `bg-emerald-50 border-emerald-400 text-emerald-800`, incorrect option becomes `bg-red-50 border-red-400 text-red-700`. All options disabled after selection.
  - Feedback: expands below options after answering — `text-sm text-muted-foreground` explanation text. Correct: `CheckCircle` Lucide icon in emerald. Incorrect: `XCircle` in red.
  - Answered questions remain visible (collapsed to show result, expandable on click).
- Questions appear in sequence; unanswered questions below the current one are visible but their options are disabled until the current question is answered.

**2d. Inline score card** (appears below last question after all 6+ answered — D-04):
- Motion entrance: `framer-motion` `opacity: 0→1, scale: 0.95→1, duration: 0.3s` (same pattern as GrammarSessionResults).
- Container: `Card` with `mx-auto max-w-lg mt-8`.
- Headline: display size (28px, semibold) — `"{score}/{total} correct"`.
- Sub-line: `"{pct}% · {readingTime}"` at `text-sm text-muted-foreground`.
- Action buttons: `"Try another passage"` (primary) + `"Browse all passages"` (outline). Both `min-h-[44px] w-full`.
- No redirect — user stays on passage page per D-04.

**2e. Word tap popover** (VOCAB-08 / D-14):
- Trigger: single click/tap on any `<span data-word>` in the passage body.
- Popover component: shadcn `Popover`. Position: above the tapped word (preferred), flips below if near viewport top.
- Popover content width: 280px max.
- Layout:
  - Word: `text-sm font-semibold text-foreground` at top.
  - Part of speech: `text-xs text-muted-foreground italic` if found in VocabularyWord table.
  - Definition: `text-sm text-foreground` if found; fallback `"Definition not yet in our vocabulary library"` at `text-sm text-muted-foreground italic` if not found.
  - Sentence context: `text-xs text-muted-foreground bg-muted rounded px-2 py-1 mt-1` — the extracted surrounding sentence with target word in `font-semibold`.
  - Divider: `Separator`.
  - "Add to SRS" button: primary variant, `min-h-[44px] w-full`. After click: button replaced with `"Added to SRS"` confirmation text + `CheckCircle` icon in emerald. Disabled after first add to prevent duplicate enrollment.
  - Dismiss: click outside popover (shadcn Popover default behavior).

**2f. Highlight tooltip** (D-07):
- Trigger: user selects (mouseup / touchend) text in the passage body.
- If selection is non-empty and within the passage container: show a small floating tooltip at the selection end point.
- Tooltip contains: `Highlighter` Lucide icon + label `"Highlight"` at `text-xs`.
- Tooltip appearance: `bg-foreground text-background rounded-md px-2 py-1 shadow-lg text-xs` (dark pill, matches Tooltip pattern).
- On click: saves highlight via `POST /api/reading/highlights`, applies `bg-amber-100/70` overlay immediately (optimistic update), dismisses tooltip.
- On save error: `Toast` error "Could not save highlight. Try again." Overlay is removed.

**2g. Notes panel** (D-08):
- Desktop: right sidebar, `w-80 shrink-0` — always visible when notes toggle is active. Slide-in animation: `translate-x-full → translate-x-0` transition 200ms.
- Mobile: bottom sheet via shadcn `Sheet` — `side="bottom"`, height `h-[60vh]`.
- Notes toggle button: in passage header action row. `StickyNote` Lucide icon. When panel is open: button has `bg-muted` active state.
- Panel contents:
  - Header: `"Notes"` at `text-sm font-semibold`, close button (`X` icon).
  - `Textarea`: `min-h-[200px]`, `placeholder="Jot down your notes about this passage..."`, auto-resize up to `max-h-[400px]`.
  - Save behavior: auto-saves on textarea blur (`POST /api/reading/notes` or `PATCH` if note exists). No explicit save button.
  - Save status: `"Saved"` with `Check` icon appears at `text-xs text-muted-foreground` for 2 seconds after save, then fades.

### Screen 3: Bookmark State (browse + passage header)

- Browse card: `Bookmark` Lucide icon (unfilled, `text-muted-foreground`) in card top-right. Filled on bookmark: `BookmarkCheck` icon with `text-amber-400`. Toggle on click — optimistic update.
- Passage header: same icons at `text-sm`, inline in action row. `"Bookmark"` / `"Bookmarked"` label beside icon.
- Bookmark add: `Toast` "Passage bookmarked." Bookmark remove: `Toast` "Bookmark removed."

## Reading Timer Contract

- Timer starts on passage page mount (`useEffect`, records `startTime = Date.now()`).
- Timer display: `Clock` Lucide icon at 16px + elapsed time formatted as `"2m 34s"` in passage header action row, `text-xs text-muted-foreground`. Updates every second via `setInterval`.
- Timer auto-stops when the last question is answered (D-03). Timer state frozen at that moment.
- `readingTimeSec` included in session complete payload.
- Timer is passive — no user control (no pause/resume).

## Accessibility Contract

- All interactive `<span data-word>` elements: `role="button"` + `tabIndex={0}` + `onKeyDown` (Enter/Space triggers popover).
- Passage `<mark>` highlight elements: `aria-label="Highlighted text"`.
- Highlight tooltip: `role="tooltip"`, announced via `aria-describedby` on the passage container.
- Timer: `aria-live="polite"` region; updates every 60s to avoid excessive announcements (visual updates every 1s but SR announces at 60s).
- Answer buttons: `aria-pressed` reflects selected state. Disabled options: `aria-disabled="true"`.
- Word popover: focus trapped inside popover when open. Close on `Escape`.
- Notes Sheet (mobile): focus trapped inside sheet when open.
- CEFR badges: existing `role="img"` + `aria-label` from `CefrBadge` component — no changes needed.
- Touch targets: all interactive elements minimum 44×44px.
- Browse card bookmark icon: icon-only toggle button must declare `aria-label="Bookmark passage"` (unfilled state) and `aria-label="Remove bookmark"` (filled/BookmarkCheck state). Label updates dynamically to reflect current toggle state.
