<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → ListeningController | JWT token validated by JwtAuthGuard before any handler runs |
| ListeningController → ListeningService | userId always sourced from req.user.userId (JWT), never request body |
| ListeningService → ListeningProgress | Compound key upsert prevents cross-user data access |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-02 | Spoofing (IDOR) | ListeningProgress upsert | mitigate | userId from req.user.userId only — `completeSession(req.user.userId, dto)` — body.userId never used |
| T-06-03 | Tampering | score/accuracy in completeSession | mitigate | Server recomputes accuracy from attempts[] array — client-supplied accuracy field is ignored; score = attempts.filter(isCorrect).length |
| T-06-04 | DoS | attempts[] array length | mitigate | Validate attempts.length <= content._count.questions; throw BadRequestException if exceeded |
| T-06-05 | Information Disclosure | Audio presigned URL | mitigate | 1-hour expiry via getSignedUrl expiresIn:3600; MinIO not publicly accessible |
| T-06-W2-SC | Tampering | npm/pip/cargo installs | mitigate | No new npm installs in this plan; all dependencies already in package.json |
</threat_model>
