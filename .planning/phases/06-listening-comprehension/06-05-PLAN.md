Content pipeline for Phase 6: ListeningCrawlerService (crawl 4 sources, download MP3 to MinIO, call Whisper for wordTimestamps, classify CEFR) and ListeningSeedService (generate exercises, batch-insert 200–300 items). Both services extend the existing PipelineModule from Phase 5.

Purpose: Delivers seed data so the browse/item pages have real content to display (LIST-01), and creates ≥3 exercise types per item (LIST-02). Session completion stores progress against seeded items (LIST-07).

Output: Two pipeline services, three CLI entry points, three pnpm scripts. Running `pnpm --filter @repo/api pipeline:seed:listening` seeds 200–300 listening items with exercises into the database.
</objective>

From RESEARCH.md Pattern 1 — Whisper worker call (callWhisperWorker):
- POST to `${WHISPER_WORKER_URL}/v1/audio/transcriptions` with FormData
- FormData fields: file (MP3 stream), model ('whisper-1'), response_format ('verbose_json'), timestamp_granularities[] ('word'), language ('en')
- Response: `{ text: string, words: Array<{ word: string, start: number, end: number, probability: number }> }`
- CRITICAL: Both `WHISPER_WORD_TIMESTAMPS=true` in docker env AND `response_format=verbose_json` + `timestamp_granularities[]=word` in FormData are required (Pitfall 1)
- Guard: if `json.words` is undefined or empty, log warning and store `wordTimestamps: null`

From RESEARCH.md Pattern 4 — generateFillMissingWords:
- Takes sentences array + CEFR word list Set
- Finds a content word ≥4 chars in the CEFR word list
- Blanks it in the sentence (case-insensitive regex replace to '___')
- Generates 3 distractors from CEFR words of similar length (±2 chars)
- Max 2 FillMissingWords per item

From PATTERNS.md — batch insert pattern:
- BATCH_SIZE = 500
- `prisma.listeningQuestion.createMany({ data: batch, skipDuplicates: true })`
- Use same pattern for listeningContent.createMany

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Pipeline → whisper-worker | Docker internal network; no public exposure; pipeline is a one-time offline script |
| Pipeline → MinIO | S3 credentials from env; MinIO on localhost:9000; audio bucket not publicly readable |
| External sources (VOA/BBC/archive.org) → Pipeline | HTML/MP3 fetched from public internet; content sanitized before DB insertion |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-11 | Tampering | crawled transcript content | mitigate | ClassifierService normalizes text; Prisma parameterized query prevents SQL injection from malformed transcript content |
| T-06-12 | Information Disclosure | MinIO audioStorageKey | mitigate | Key is an opaque UUID-based path — not guessable; presigned URL is the only access path (plan 02) |
| T-06-13 | DoS | unlimited crawl depth | mitigate | Each source crawl takes a `limit` parameter (max 75 items); validate-listening checks selectors before bulk crawl |
| T-06-W5-SC | Tampering | npm/pip/cargo installs | mitigate | No new npm packages installed in this plan (fastest-levenshtein installed in Plan 04; all others already in package.json) |
