    startSession(userId, dto):
    - Resolve user cefrLevel from User table (findUniqueOrThrow select cefrLevel) — authoritative, not from body.

    - Topic type: same per-table queries PLUS a topic filter (passage.topic / content.topic / vocabularyWord.topic; grammar via topic.title or area.name). If a table yields fewer than its quota, backfill from other modules to keep total at 10 where possible (D-07 nearest even split).

    - Vocabulary: synthesize MC (prompt "What is the meaning of '{word}'?", answer = definition, distractors = 3 random other-word definitions, explanation = examples[0] ?? null).
    - Return { sessionId, questions }.
    completeSession(userId, sessionId, dto):
    - findFirst QuizSession { id: sessionId, userId } — throw NotFoundException if null (IDOR guard).
    - if session.completedAt != null -> throw BadRequestException('Session already completed').
    - Recompute accuracy server-side: correct = answers.filter(isCorrect).length; accuracy = total>0 ? correct/total*100 : 0; score = correct. IGNORE any client-supplied accuracy.
    - createMany QuizAnswer rows from dto.answers (sessionId, questionRef, skillArea, isCorrect, userAnswer, correctAnswer, xpEarned per answer = calculateXp(QUIZ_CORRECT, cefrLevel) when isCorrect else 0).
    - totalXp = sum of correct-answer XP + calculateXp(QUIZ_SESSION_BONUS, cefrLevel). Call gamification.awardXp(userId, totalXp, 'quiz_session', 'MIXED', sessionId).
    - Call gamification.checkAchievements(userId, { type: 'QUIZ_COMPLETE', metadata: { sessionId } }).
    - Update QuizSession { score, accuracy, timeTakenSec, xpEarned: totalXp, completedAt: now }.
    - incorrectAnswers = re-hydrate the questionRefs where isCorrect=false into QuizQuestionDto.
    - Return { score, accuracy, xpEarned, levelUp, newLevel, newAchievements, incorrectAnswers }.
    getMistakes(userId, sessionId): findFirst session scoped by userId (NotFound if null); load QuizAnswer where isCorrect=false; re-hydrate to QuizQuestionDto; return { incorrectAnswers }.

|-----------|----------|-----------|-------------|-----------------|

| T-07-08 | Tampering | Replay / double-complete (question fishing) | mitigate | `session.completedAt != null` guard throws BadRequestException on second complete |
| T-07-09 | Spoofing | userId in request body | mitigate | userId sourced from `req.user.userId` (JWT) only; DTO has no userId field |
