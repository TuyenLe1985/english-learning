## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline question meta |
| sm | 8px | Between label and input, within question option list |
| md | 16px | Default card padding, section spacing within a question |
| lg | 24px | Between question header and answer options, section breaks on results screen |
| xl | 32px | Between major page sections (quiz header / question body / nav footer) |
| 2xl | 48px | Page-level vertical rhythm on browse and results pages |
| 3xl | 64px | Not used in Phase 7 — no full-bleed hero sections |

Exceptions:
- Touch targets on quiz answer option buttons: minimum `min-h-[44px]` (matches established pattern in PassageScoreCard, ListeningScoreCard, GrammarSessionResults — source: existing codebase)
- Level-up modal: centered overlay with `p-8` (32px) inner padding and `max-w-sm` (matches Dialog pattern)
- XP toast: fixed position `bottom-4 right-4` (16px from edges) — consistent with bottom-right toast convention

## Screen Inventory

### Screen 1: Quiz Browse (`/quiz`)

**Layout:** Centered content column, `max-w-3xl mx-auto`. Page heading "Quiz Center" at 20px semibold. Subtitle at 14px muted: "Test your knowledge across all skills."

**Card grid:** 2 columns on md+, 1 column on mobile. Cards use `rounded-xl border border-border bg-card p-5 shadow-sm hover:shadow-md` (matching GrammarAreaCard pattern).

**Quiz type cards (6 total):**
- "Mixed Skill" — icon: `Shuffle` from lucide-react, label, subtitle: "Grammar, Vocabulary, Reading + Listening"
- "Technology" — icon: `Monitor`
- "Travel" — icon: `Plane`
- "Business" — icon: `Briefcase`
- "Daily Communication" — icon: `MessageCircle`
- (5th topic if needed): "Education" — icon: `GraduationCap`

Each card shows: icon (32×32), topic name (14px semibold), question count or "10 questions" label (12px muted), CefrBadge for user's current level (bottom-left), "Start Quiz →" affordance (no full button — entire card is the link target).

**Empty state:** Not applicable — quiz types are hardcoded, always present.

### Screen 2: Quiz Session (`/quiz/[sessionId]`)

**Layout:** Centered, `max-w-2xl mx-auto`. Fixed header row: progress bar + "Question 3 of 10" counter + elapsed timer (optional display only — D-05).

**Progress bar:** Full-width `Progress` component, value = `(currentIndex / 10) * 100`. Below bar: `text-sm text-muted-foreground` label "3 / 10".

**Question area:** Card with `p-6`. Top row: skill area Badge (`variant="secondary"`) + CEFR badge. Question stem at 16px regular. Answer options rendered by delegating to skill-specific exercise component.

**Answer lock:** After selecting an answer, options become disabled. Selected option gets `border-primary ring-1 ring-primary` highlight. A "Next →" Button (primary variant, `min-h-[44px]`) appears. No back-navigation affordance.

**No time limit UI:** Clock icon may appear in header showing elapsed time in `MM:SS` format as passive display. No countdown, no urgency styling.

### Screen 3: Quiz Results (`/quiz/[sessionId]/results`)

**Layout:** Centered, `max-w-lg mx-auto`. Framer Motion entrance: `initial={{ opacity: 0, scale: 0.95 }}`, `animate={{ opacity: 1, scale: 1 }}`, `transition={{ duration: 0.3, ease: 'easeOut' }}` — matches PassageScoreCard and ListeningScoreCard pattern exactly.

**Score headline:** `text-[28px] font-semibold` — "{score}/10 correct"
**Sub-line:** `text-sm text-muted-foreground` — "{pct}% accuracy · {xpEarned} XP earned · {timeTaken}"

**Skill breakdown table:** Four rows (Grammar / Vocabulary / Reading / Listening), each showing `{correct}/{attempted}` — same `<dl>` pattern as ListeningScoreCard.

**CTA buttons (full-width, stacked):**
1. "Review Mistakes" — primary variant (only shown if `incorrectCount > 0`)
2. "Try Another Quiz" — outline variant
3. "Back to Quiz Center" — ghost variant or link

**XP toast:** Appears on mount via AnimatePresence. Fixed bottom-right, `z-50`.
**Level-up modal:** Appears on mount if `levelUp === true` in API response, rendered over score card via Dialog.

### Screen 4: Mistake Review (`/quiz/[sessionId]/results/mistakes` or inline tab)

**Layout:** Stacked question cards, `max-w-2xl mx-auto`. Each card shows:
- Question stem (full, re-rendered)
- All answer options
- User's wrong answer: `bg-destructive/10 border-destructive/30 text-destructive`
- Correct answer: `bg-green-50 border-green-300 text-green-700` (consistent with correct-answer states in Grammar module)
- Explanation: `text-sm text-muted-foreground italic` below correct answer

**Navigation:** "Back to Results" link at top. No pagination — all mistakes shown on one scrollable page.

### Screen 5: Profile Page Additions (augment existing `/profile` page)

**Level badge:** Circular badge `w-12 h-12` next to avatar. Shows level number at 20px semibold. Background: `bg-primary text-primary-foreground rounded-full`.

**XP progress bar section:** Below CEFR badge. Shows "Level {n}" label, `Progress` bar, "450 / 500 XP to Level {n+1}" at 12px muted. `min-h-[8px]` bar height.

**Achievement grid:** Heading "Achievements" at 20px semibold, `mt-8`. 4-column grid on md+, 2-column on mobile. Each `AchievementBadge` tile: icon (24×24 lucide icon or emoji) + `text-xs font-medium` name + `text-xs text-muted-foreground` earned date (or "Locked" in muted for unearned).

## Interaction Contract

### Quiz Session State Machine

```
IDLE → LOADING (fetch questions) → ACTIVE (question 1..10) → SUBMITTING → RESULTS
                                      ↑ answer + lock + next ↑
```

- **IDLE → LOADING:** On "Start Quiz" tap. Show `Skeleton` loader in question area.
- **LOADING → ACTIVE:** Questions array arrives. Render question 1. Progress bar = 10%.
- **ACTIVE (answer selected):** Options become `disabled`. Selected option gets primary ring. "Next →" Button appears.
- **ACTIVE → next question:** `currentIndex++`. Progress bar animates to `(index/10)*100`.
- **Question 10 answered:** Button label changes to "Submit Quiz".
- **ACTIVE → SUBMITTING:** POST to API. Show loading spinner on Submit button.
- **SUBMITTING → RESULTS:** Results screen mounts with Framer Motion entrance. XP toast + level-up modal fire from `useEffect` on mount.
- **No back-navigation:** Once an answer is submitted for a question, the index only increments. Disable browser Back button navigation warning is not required (no data loss on back — answers are in client state).

### Achievement Toast Sequencing

If a session-complete response returns both `xpAwarded` and `newAchievements[]`:
1. XP toast fires first (bottom-right, z-50)
2. Achievement toast(s) fire 500ms after XP toast appears, stacked above (bottom-right, z-51)
3. Level-up modal fires after 1 second if `levelUp: true`, centered overlay

### Answer Option Accessibility

- Each answer option rendered as a `<button>` with `role="radio"` semantics or as a labeled `<RadioGroup>` from Radix (via shadcn).
- Selected state: `aria-checked="true"` or `aria-pressed="true"`.
- Disabled state: `aria-disabled="true"` after lock.
- Correct answer on mistake review: `aria-label="Correct answer: {text}"`.
- Incorrect (user's) answer on mistake review: `aria-label="Your answer (incorrect): {text}"`.
