FTS query (RESEARCH.md Pattern 2 — CRITICAL field names):
  - VocabularyWord: SELECT id, 'vocabulary' AS type, word AS title, ts_headline('english', definition, plainto_tsquery('english', ${q}), 'StartSel=<mark>,StopSel=</mark>,MaxWords=15,MinWords=10') AS snippet, "cefrLevel", topic; WHERE to_tsvector('english', word || ' ' || definition) @@ plainto_tsquery('english', ${q})
  - GrammarLesson: JOIN GrammarTopic gt ON gl."topicId" = gt.id; use gl.explanation (NOT content — Pitfall 1); cefrLevel from gt (GrammarLesson has no cefrLevel — A4); WHERE to_tsvector('english', gl.title || ' ' || gl.explanation) @@ plainto_tsquery(...)
  - ReadingPassage: title || ' ' || content; AND "isPublished" = true
  - ListeningContent (NOT ListeningItem — Pitfall 2): title || ' ' || "transcriptText"; AND "isPublished" = true
  - Outer LIMIT 100 (Pitfall 5)

Filters (SRCH-03): level (B1/B2/C1), topic, skill (grammar/vocabulary/reading/listening). skill set → include only that branch. level/topic → per-branch WHERE clauses. Use Prisma.sql / Prisma.join for dynamic fragments — NEVER string-concatenate user input.

DTO (search.dto.ts mirrors packages/shared/src/search.dto.ts): SearchResultDto {id,type,title,snippet,cefrLevel,topic}; group into SearchResultGroupDto[] {type,count,results} ordered Vocabulary · Grammar · Reading · Listening (Quiz omitted — D-11). Response {query,total,groups}.

Controller (08-PATTERNS.md): SearchController already @Controller('search'); add @UseGuards(JwtAuthGuard) @Get() with @Query('q'), @Query('level'), @Query('topic'), @Query('skill'). Empty/blank q → empty groups (skip query).

SQL injection (Security Domain): plainto_tsquery + Prisma tagged template `${q}` auto-parameterizes — safe. Never interpolate filter values into a raw SQL string; use Prisma.sql.
