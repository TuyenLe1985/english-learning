Student analytics (ANLT-01): getStudentAnalytics(userId) returns AnalyticsDto:
  - cefrProgression: CefrHistory.findMany where userId orderBy recordedAt → map to {month, level: B1=1/B2=2/C1=3} (date-fns format month)
  - vocabRetention: derive from SrsCard recall (correct reviews / total) grouped by week — use existing SrsCard fields; if no card history, return []
  - learningTime: XpEvent grouped by day (date-fns) as a proxy for minutes, or ActivityLog count → minutes estimate; return {date, minutes}
  - activityHeatmap: ActivityLog grouped by loggedAt::date for last 365 days → {date, count, level: 0-4 via D-16 mapping 0=0, 1-3=1, 4-7=2, 8-10=3, 11+=4}
  - skillBreakdown (ANLT-01 "skill breakdown"): SkillScore.findMany where userId → map to SkillScoreDto[] {skillArea, accuracy, isWeak} ordered Grammar · Vocabulary · Reading · Listening (missing skills default accuracy 0 / isWeak false)

Admin analytics (ANLT-02): getAdminAnalytics() cache-aside on key 'admin:analytics:v1' (RESEARCH.md Pattern 4): check redisCache.get → return on hit; else compute then set(key,data,300). Compute: dau (User/ActivityLog active last 1d), wau (7d), mau (30d) via distinct userId in ActivityLog windows; retentionRate = users active in week 2 after signup / signups (User.createdAt windows); topContent top 10 most-completed (ReadingProgress + ListeningProgress + QuizSession completedAt counts grouped by content); completionRateByModule (ANLT-02 "average completion rates by module"): for each module (grammar, vocabulary, reading, listening, quiz) compute completed sessions / total sessions × 100 via $queryRaw or Prisma groupBy → Array<{module, rate}>; userGrowth cumulative User.createdAt by day; lastUpdated ISO string. Return AdminAnalyticsDto.

Controller (08-PATTERNS.md): AnalyticsController already @Controller('analytics'). Add:
  - @UseGuards(JwtAuthGuard) @Get('me') → getStudentAnalytics(req.user.userId)  (userId from JWT — IDOR prevention)
  - @UseGuards(JwtAuthGuard, RolesGuard) @Roles('ADMIN') @Get('admin') → getAdminAnalytics()
  Order matters: JwtAuthGuard BEFORE RolesGuard so req.user is populated (RESEARCH.md Pattern 3). Use 'ADMIN' literal (Pitfall 3).

DTO shapes: packages/shared/src/analytics.dto.ts AnalyticsDto + AdminAnalyticsDto.
